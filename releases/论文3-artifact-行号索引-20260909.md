### A.8 证明自动化与典型证明片段

**证明自动化总览**。本文引用证明的自动化以 Coq 标准 tactic 为主，分层覆盖如下：

- **`ring`/`field`/`lia`**：Q 层与索引层主力。`ring` 闭合有理数环等式（如 esq_eq_corr 归纳步收尾的 `unfold Qminus; ring`，L12864/L12867）；`field` 处理含除法目标并生成分母非零前提，由 `q_neq_of_lt; apply q_fact_pos` 类引理闭合（esq_eq_corr 的 m=1 分支，L12848–L12850）；`lia` 处理 nat/Z 线性算术（如归纳步中 `(1 <= Datatypes.S m'')%nat` 前提，L12862；及 `corr_diff_eq_sq_diff` 内索引恒等 `2·m+2·m+2 == 4·m+2`，L12830）。按正则词匹配（含注释文本）的量级估计（未逐类复验，复验命令随 artifact 提供）：`ring` ≈ 1.8k 处、`lia` ≈ 1.7k 处、`field` ≈ 0.3k 处、`nra` ≈ 38 处——nra 仅少量使用，不是主链工具。
- **setoid 重写族**：`setoid_rewrite`/`setoid_replace` 用于 Qeq 与 real_eq 等式链及 Proper 重写（`real_eq_mult_compat` 等 Proper 族为接口实例提供替换前提，附录 A.4）；eq 层 `rewrite` 用于定义展开与索引改写。
- **自定义 Ltac**：库内顶层 `Ltac` 定义 4 条——L1125/L1131/L1134（`id_simpl_step`/`id_simpl`/`id_ring`，Id 层化简辅助）与 L72194 `b4_qring`。`b4_qring` 是 Real 层「逐点 proj 穿透」自动化：`apply real_eq_of_zero_diff; intro n; repeat (first [rewrite real_plus_proj | rewrite real_opp_proj | rewrite real_mult_proj | rewrite real_const_proj]); cbn [projT1 real_zero real_one]; simpl; try ring; try field`——把 Real 层点式环恒等约化为 Q 层 ring/field。其注释明示使用边界（L72189–L72193）：**不得用于含 inv/abs 的目标**（inv 逐点不成立；abs 的 projT1 保持为原子）——自动化边界以注释固化是本库惯例。`b4_qring` 服务于 Real 层 lift/序列代数批（服务于 `p2_smoke1`/`p2_smoke2` 等验证性小件，L72205–L72212），不在 esq/exp_pos 主链证明体内；esq_eq_corr 本体不使用自定义 Ltac。

**典型证明片段：`esq_eq_corr` 归纳步（逐字机器脚本，根 219，L12837 → Qed L12868，31 行）**。§5.1 的代码框为示意形态（含 `unfold ...` 省略与简化），此处为机器脚本原样——两者不一致处以本片段为准：

```coq
Lemma esq_eq_corr : forall (a : Q) (m : nat),
  e_sum m a * e_sum m a - o_sum m a * o_sum m a == 1 + corr m a.   (* L12837 *)
Proof.
  intros a m.
  induction m as [| m' IH].
  - (* m=0：E_0=1、O_0=0、corr 0=0 *)
    simpl. reflexivity.
  - destruct m' as [| m''].
    + (* m=1：直接计算 *)
      unfold e_sum, o_sum, corr, kloop, inner2, brk2.
      simpl.
      field.
      all: repeat (split; [apply q_neq_of_lt; apply q_fact_pos | idtac]);
           apply q_neq_of_lt; apply q_fact_pos.
    + (* m = S(S m'')：step——corr 差分公式 + IH *)                 (* L12851 *)
      assert (Hstep : e_sum (Datatypes.S (Datatypes.S m'')) a * e_sum (Datatypes.S (Datatypes.S m'')) a -
                      o_sum (Datatypes.S (Datatypes.S m'')) a * o_sum (Datatypes.S (Datatypes.S m'')) a ==
                      (e_sum (Datatypes.S m'') a * e_sum (Datatypes.S m'') a -
                       o_sum (Datatypes.S m'') a * o_sum (Datatypes.S m'') a) +
                      (corr (Datatypes.S (Datatypes.S m'')) a - corr (Datatypes.S m'') a)).
      { assert (Hd : corr (Datatypes.S (Datatypes.S m'')) a - corr (Datatypes.S m'') a ==
                     (e_sum (Datatypes.S (Datatypes.S m'')) a * e_sum (Datatypes.S (Datatypes.S m'')) a -
                      o_sum (Datatypes.S (Datatypes.S m'')) a * o_sum (Datatypes.S (Datatypes.S m'')) a) -
                     (e_sum (Datatypes.S m'') a * e_sum (Datatypes.S m'') a -
                      o_sum (Datatypes.S m'') a * o_sum (Datatypes.S m'') a)).
        { apply (corr_diff_eq_sq_diff a (Datatypes.S m'')). lia. }   (* L12862 *)
        setoid_rewrite Hd.
        unfold Qminus. ring. }
      setoid_rewrite Hstep.
      setoid_rewrite IH.
      unfold Qminus. ring.
Qed.                                                             (* L12868 *)
```

归纳步的机械结构即本库 Q 层证明的典型形态：先以 `assert` 引入 `corr_diff_eq_sq_diff` 给出的差分等式（`lia` 闭合 `1 ≤ S m''` 前提），再两次 `setoid_rewrite`（Hstep、归纳假设 IH）把目标归约到纯环恒等，最后由 `ring` 收尾——「重写到只剩环恒等，由自动化闭合」。
